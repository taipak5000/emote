# エモート画像の置き場所・ファイル名一覧

エモートのサムネイル画像は、このフォルダ（`icons/`）に直接置いてください。
`index.html` 側は既に `icons/<id>.png` を読み込むようになっているので、
正しいファイル名で置くだけで自動的に反映されます（コード側の追加対応は不要です）。

- 置き場所: `icons/`
- ファイル形式: `.png`
- ファイル名: 下表の `id` の列そのまま（例: `emote_001.png`）
- サイズ目安: 正方形（例: 256×256 / 512×512 など）。背景透過推奨（`emote-tile-img-wrap` が
  中央寄せ・余白調整するので、多少サイズが違っても大きな問題はありません）
- まだ画像が無いものは 🎭 のフォールバック表示になります（`onerror` で自動的に切り替わります）ので、
  一部から順番に追加していく形でも問題ありません。
